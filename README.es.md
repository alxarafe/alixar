# Alixar ERP

Alixar es una reescritura de Dolibarr utilizando el Framework Alxarafe.

## Requisitos

- PHP 8.5+
- Composer
- Docker (opcional)

## Instalación

1. Clona el repositorio.
2. Ejecuta `composer install`.
3. Configura tu archivo `.env`.
4. Ejecuta las migraciones usando `./bin/run_migrations.sh`.
